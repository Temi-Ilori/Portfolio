# Portfolio Site

This is a lightweight single-page portfolio built with plain HTML, CSS, and JavaScript.

## Edit your content

Update the `portfolio` object in [script.js](/Users/temiilori/Library/Mobile Documents/com~apple~CloudDocs/Portfolio/script.js).

Fields you will likely want to change first:

- `name`
- `linkedin`
- `email`
- `summary`
- `about`
- `projects`

## Preview locally

Run:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
